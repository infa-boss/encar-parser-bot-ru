# Encar Parser Bot — мониторинг авто из Кореи на Encar.com

🤖 Telegram бот: https://t.me/EncarNewParserBot

Telegram бот который отслеживает новые объявления на Encar.com — крупнейшем автомобильном сайте Кореи. Каждую минуту проверяет новые авто, конвертирует цены из корейских вон в доллары и отправляет в Telegram канал.

## Возможности
- 🔄 Проверяет новые объявления каждую минуту
- 💰 Конвертирует корейские воны в доллары по актуальному курсу
- 🟢 Помечает объявления до $15,000
- 🔴 Помечает объявления выше $15,000
- 📩 Мгновенно отправляет в Telegram канал
